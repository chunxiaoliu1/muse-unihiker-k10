UNIHIKER K10 / MUSE GADGETS

Connect your K10 to Muse

Set up Muse and optional voice replies over USB.

1 · Connect your device

Connect K10 with a USB data cable and open this page in Chrome or Edge on your computer.

For first-time setup, connect when the screen says Set SDK Token first. If your device is already set up, select USB mode in its menu first. Restart K10 to leave USB mode.

Not connected

Can't connect?

Close other pages or serial tools connected to K10, then try again. If you just flashed the firmware, release BOOT and press RESET once.

2 · SDK Token

Get your token from Account → SDK tokens at gadgets.muse.ai. It starts with mgst_.

Your token is saved only on K10, never uploaded or stored in your browser. Leave this blank to keep an existing token.

Connect to check your settings.

3 · Voice replies (optional)

Add a Cartesia API Key to have K10 read Muse's replies aloud. Skip this during first-time setup for text-only replies.

Leave this blank to keep existing voice settings. Enter your key again to change the voice or language.

Your key is saved only on K10. Voice replies need internet access, send reply text to Cartesia, and use your service credits.

To test saved voice settings, restart K10, enter USB mode again, and reconnect to this page.

Connect to check voice settings.

Clear settings or switch accounts

Clearing only the SDK Token takes effect after a restart. Pairing, Wi-Fi, and voice settings are kept.

Before switching accounts or giving the device to someone else, clear all user settings and remove the old device in the Muse app. This also clears Wi-Fi and your Cartesia key, so you will need to set up K10 again.

Save the SDK Token and voice settings entered above together. K10 restarts after everything is saved. For first-time setup, enable Developer mode in the Muse app, add the device, and set up Wi-Fi.

Ready to connect.

After setup, you can close this page and disconnect USB. To change settings later, select USB mode in K10's menu.
